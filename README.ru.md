# Vision

Пространственные окна в Minecraft — в духе visionOS.

Vision — клиентский мод для Fabric, который добавляет в мир парящие панели из матового стекла.
Окно ставится перед игроком, таскается за полоску под ним, растягивается за углы, а если установлен
MCEF — в него загружается настоящая веб-страница с работающими мышью и клавиатурой.

Всё управление — взглядом: прицел работает как курсор и превращается из ванильного крестика
в кольцо, когда наведён на окно.

## Возможности

- **Пространственные панели.** Окна — реальные квады в мировом пространстве с полным 3D-трансформом.
  При открытии разворачиваются лицом к игроку, при перетаскивании плавно следуют за ним.
- **Матовое стекло.** Фон размывается пирамидой Dual Kawase (7 уровней, downsample → tent-upsample).
  Форма, скруглённые углы и рим-блики считаются в SDF-фрагментшейдере.
- **Взаимное размытие.** Фон каждого окна собирается отдельно из «мира плюс все *прочие* окна»,
  поэтому панели размывают друг друга симметрично и размытие не скачет, когда окна меняются
  местами по глубине.
- **Прямое управление.** Полоска-ручка под окном для перетаскивания, скролл — приблизить или
  отдалить, угловые ручки, вырастающие в дугу при ресайзе, и кнопка закрытия, разворачивающаяся
  из точки в крестик при наводке.
- **Веб-окна.** Встроенная страница Chromium, отрисованная прямо на панель через
  [MCEF](https://github.com/CinemaMod/mcef), с передачей кликов, скролла и клавиатуры.
- **Честный хром.** Плотность пикселей у окна фиксирована, поэтому ресайз перекладывает контент,
  а не растягивает его, и скруглённые углы никогда не превращаются в эллипсы.

## Требования

| | |
|---|---|
| Minecraft | 1.21.4 |
| Fabric Loader | 0.19.3 или новее |
| Fabric API | 0.119.4+1.21.4 |
| Java | 21 |
| [MCEF](https://github.com/CinemaMod/mcef) | 2.1.6-1.21.4 |

MCEF — отдельный мод, в jar он **не** бандлится: ставьте его рядом с Vision.
При первом запуске он сам докачивает нативные бинарники CEF.

## Управление

| Действие | Что происходит |
|---|---|
| `V` | Открыть пустое демо-окно |
| `B` | Открыть веб-окно |
| ЛКМ по полоске под окном | Схватить и тащить окно |
| Скролл во время перетаскивания | Приблизить / отдалить окно |
| ЛКМ по ручке нижнего угла | Изменить размер окна |
| ЛКМ по точке слева от полоски | Закрыть окно |
| ЛКМ по странице | Отправить клик странице и забрать фокус клавиатуры |
| `Esc` | Вернуть фокус клавиатуры игре |

Пока окно держит фокус клавиатуры, нажатия уходят ему, а не игре.

## Сборка

```sh
./gradlew build
```

Jar появится в `build/libs/`. Запуск клиента для разработки:

```sh
./gradlew runClient
```

## Структура проекта

```
client/os/          Модель окна, менеджер окон, маршрутизация ввода
client/os/apps/     Содержимое окон: DemoApp, WebContent (браузер MCEF)
client/render/      Отрисовка в мире, размытие Dual Kawase, прицел
client/ui/          UiCanvas — 2D-API рисования, который видит содержимое окна
mixin/              Перехват прицела, мыши и клавиатуры
resources/assets/vision/shaders/core/   GLSL: стекло, веб, полоска, ручка, кнопка, блюр
```

## Своё окно

Содержимое окна — это что угодно, реализующее `WindowContent`. Оно рисует в собственном
пиксельном пространстве через `UiCanvas` и получает события мыши и клавиатуры в тех же координатах:

```java
public class ClockApp implements WindowContent {
    @Override
    public String title() {
        return "Clock";
    }

    @Override
    public void render(UiCanvas g) {
        g.textCentered(LocalTime.now().toString(), g.width() / 2f, g.height() / 2f, 0xFFFFFFFF);
    }
}
```

Открыть его перед игроком на 2.5 блока:

```java
Window window = new Window(new ClockApp(), 480, 320, 3.0f, 2.0f);
WindowManager.INSTANCE.open(window, 2.5f);
```

Последние четыре аргумента — внутреннее разрешение в пикселях и физический размер в блоках.
Их отношение фиксирует плотность пикселей на всё время жизни окна.
